# 5. CHARACTER STUDIO — ADDITIONAL NARRATOR REQUIREMENTS

**Continues from Section 4 — Character Studio (CS-01 to CS-08).**

Preserve the previously introduced Stage 3 addendum and its requirements CS-09 to CS-12.

## CS-09 — Automatic Narrator Identification and Assignment

Identify the difference between character dialogue and narration.

Recognise quotation formats including:

- "..."
- “...”
- ‘...’
- 「...」
- 『...』

Also identify unquoted dialogue through AI analysis and existing manual assignments.

Classification rules:

| Identified content | Required result |
|---|---|
| Identified character dialogue | Assign to that character |
| Unidentified quoted dialogue | Needs Speaker Review |
| Identified non-dialogue prose | Narrator |
| Ambiguous text | Review Required |

Non-dialogue prose must automatically be assigned to the reserved Narrator role.

Unidentified quoted dialogue must never silently become Narrator dialogue under the normal character-assignment workflow.

Manual assignments must take precedence over automatic identification.

Store the exact passage, chapter, text positions and assignment provenance.

Reanalysis must not duplicate or overwrite confirmed assignments.

## CS-10 — Series-Level Default Narrator Voice

Add narrator voice selection to Create Series.

Requirements:

- Load saved Voice Studio profiles.
- Select by profile name, provider and model.
- Preview the narrator voice.
- Save the default narrator profile for that series.
- Show it in series details.
- Allow changing it later.
- New projects inherit the current series default.

## CS-11 — Project-Level Narrator Override

A project can inherit the series narrator or independently select its own narrator.

Provide:

- Project-level narrator selection.
- Save project-specific override.
- Reset to Series Default.
- Correct inheritance when a series narrator changes.
- Protection for projects with their own overrides.
- Clear indication of whether the effective voice comes from Series Default or Project Override.

Changing one project's narrator must not change another project's independent override.

## CS-12 — Narrator Preview and Production Routing

Provide an actual narrator preview using selected narration text and the effective project narrator profile.

Normal production routing:

| Text type | Voice routing |
|---|---|
| Confirmed narration | Effective project narrator |

# 9. NEW REQUIREMENT — NARRATOR-ONLY AUDIOBOOK GENERATION

**GEN-07 — Narrator-Only Audiobook Generation When No Character Profile Has Been Added [P0].**

This is an additional explicit production requirement.

The user must be able to generate a complete audiobook using only the selected narrator voice when no character voice profiles have been added to the active project.

The absence of character profiles must not unnecessarily prevent audiobook generation.

## 9.1 Activation condition

When the active project contains zero configured character voice profiles and has a valid narrator profile:

- Allow narrator-only audiobook generation.
- Do not require the user to create character profiles merely to make generation possible.
- Automatically use Narrator-Only Mode.
- Clearly communicate the selected production mode before generation.

## 9.2 Narrator-only voice routing

In Narrator-Only Mode:

- Use the effective selected narrator profile for the entire book.
- Read narration using the narrator voice.
- Read character dialogue using the same narrator voice.
- Do not require separate character voice profiles.
- Do not create dummy character profiles or artificial character assignments.
- Preserve the original text and dialogue formatting.
- Preserve the selected narrator's voice identity throughout all chapters.

The purpose is to let users produce a complete audiobook with one narrator without having to configure a separate voice for every character.

## 9.3 Production Studio UI

Show a clear status:

**Narrator-Only Generation**

Display:

- Selected narrator name.
- Provider.
- Model.
- Narrator readiness.
- Character profiles configured: 0.
- Effective production mode: Narrator Only.

Show an informative message:

" No character voice profiles have been added to this project. The complete audiobook will be narrated using your selected narrator voice."

The Character Voices readiness item must not be displayed as a blocking failure when Narrator-Only Mode is valid.

It should instead show that character profiles are not configured and narrator-only production is permitted.

## 9.4 Generation readiness rules

Narrator-only generation is permitted when:

1. The project has valid source text.
2. Required chapters are available.
3. The effective narrator profile exists.
4. The narrator provider, model and runtime are available.
5. Required output settings and storage are valid.
6. No other mandatory generation blocker exists.
7. No character voice profiles have been added to the active project.

A missing or unavailable narrator must still block generation.

The lack of character profiles alone must never block generation.

## 9.5 Behaviour when character profiles are added later

When one or more character voice profiles are subsequently added:

- Use the normal narrator and character voice-routing workflow.
- Preserve all existing character assignments.
- Route confirmed character dialogue to its assigned character voice.
- Route narration to the effective narrator voice.
- Identify missing character assignments through normal readiness checks.
- Do not silently substitute narrator-only routing for a configured multi-character project.

Narrator-only generation must be available because no character profiles have been configured, not because the system failed to load an existing character profile.

## 9.6 Preview and final-generation consistency

Apply the same narrator-only mode to:

- Voice previews using the narrator.
- Selected-chapter previews.
- Selected-chapter generation.
- Full audiobook generation.
- Resumed generation.
- Final assembly.

The actual voice used must match the narrator displayed in Production Studio.

## 9.7 Persistence, caching and recovery

- Store the effective generation mode in the job's settings snapshot.
- Preserve narrator-only routing through application restart.
- Preserve it during pause/resume and recovery.
- Include the effective narrator profile in generation/cache signatures.
- Invalidate incompatible cached audio if the effective voice or routing configuration changes.
- Do not incorrectly reuse audio generated under a previous character-routing configuration.

## 9.8 Acceptance criteria

- A project with no character profiles and a valid narrator can generate a full audiobook.
- All dialogue and narration use the selected narrator voice in Narrator-Only Mode.
- No artificial character profiles are created.
- Production readiness does not block generation merely because character profiles are absent.
- The narrator identity remains consistent across chapters.
- Preview and final generation use the same narrator routing.
- Restarting the application preserves the correct configuration.
- Adding character profiles later activates the normal multi-character workflow.
- Missing or unavailable narrator profiles correctly prevent generation.

**Important:** Narrator-only generation is an intentional production mode. It must not be represented as successful AI character identification or as individually assigned character voices.
