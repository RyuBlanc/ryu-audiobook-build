Ryu's Audiobook End-User Agreement

Ryu's Audiobook stores projects, imported books, generated previews and production history locally unless an online provider is explicitly configured.

Voice-reference features must only be used with audio the user is authorized to process. The application must not be used to impersonate another person.

Online voice providers may transmit selected text or audio according to the provider configuration shown inside Dragon Studio. Credentials must be stored securely by the installed application.

The setup program may create application files, Start menu entries, a desktop shortcut and an uninstaller registration.
